## 🎯 CUSTOM ROLE GUIDE

### Sheriff Role 🔫
**Ability:** Can shoot players  
**Win Condition:** Eliminate all Impostors

**Usage:**
1. Cooldown: 30 seconds (configurable)
2. Click player to shoot
3. ✅ Kill Impostor → Success
4. ❌ Kill Crewmate → You die too

**Strategy:**
- Don't shoot randomly
- Gather evidence first
- Use in late game
- Coordinate with crew

### Jester Role 🤡
**Ability:** None  
**Win Condition:** Get voted out

**Usage:**
1. Act suspicious (but not too obvious)
2. Create chaos in meetings
3. Give conflicting stories
4. Get voted out to win alone

**Strategy:**
- Don't be too obvious
- Frame yourself subtly
- Create suspicion
- Avoid being killed

### Engineer Role 🔧
**Ability:** Use vents like Impostor  
**Win Condition:** Complete all tasks

**Usage:**
1. Press vent button to enter
2. Travel quickly between areas
3. Access vent network
4. Exit at strategic locations

**Strategy:**
- Use vents for fast travel
- Check cameras from vents
- Surprise check on players
- Escape dangerous areas

### Medic Role ⚕️
**Ability:** Shield players  
**Win Condition:** Keep crew alive

**Usage:**
1. Select player to shield
2. Shield prevents one kill
3. See who killed shielded player
4. Report to crew

**Strategy:**
- Shield confirmed crew
- Shield yourself in danger
- Track shield breaks
- Use info to find Impostor

## 🔧 TROUBLESHOOTING

### Issue: "Mod not loading in game"
**Solutions:**
1. Check BepInEx is installed correctly
2. Verify game version compatibility
3. Re-run installer as administrator
4. Check security software didn't block files

### Issue: "Game crashes on startup"
**Solutions:**
1. Remove conflicting mods
2. Update BepInEx to latest version
3. Verify game files in Steam
4. Clear mod cache folder

### Issue: "Custom roles not appearing"
**Solutions:**
1. Check you're in modded lobby
2. Verify host has mod installed
3. Check role spawn rates > 0%
4. Restart game and rejoin

### Issue: "Mod menu not opening (INSERT key)"
**Solutions:**
1. Try alternative key (F1 or Home)
2. Check keyboard works in other games
3. Re-bind mod menu key in config
4. Run game as administrator

### Issue: "Banned from public lobbies"
**Solutions:**
1. Only use in private lobbies
2. Don't use advantage mods online
3. Create own lobby with friends
4. Appeal ban (if unfair)

### Issue: "Cosmetics not unlocking"
**Solutions:**
1. Check cosmetic unlocker is enabled
2. Restart game to apply changes
3. Verify mod version is latest
4. Manually edit cosmetic config
